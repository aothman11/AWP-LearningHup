# FI-ORG-050 Depreciation Area

| FI-ORG-050: Depreciation Area |

## Definition 

The depreciation areas are defined with a two-digit numeric key. The numeric keys represent depreciation terms that you can enter in the asset master record or in the asset classes. Values and depreciation are posted to the general ledger. Depreciation area 01 is the leading depreciation area. Values and depreciation are posted to the general ledger.

| Depreciation Area |
| --- |
| Code | Description | Real | Target Group | Accounting Principle | GL |
| 01 | IFRS in local currency | X | 0L | IFRS | 1 Area posts in Real Time |
| 02 | Local Tax in local currency | X | 0L | IFRS | 0 Area Does Not post |
