## Definition 

Company Code (for external purposes) A company code represents an independent balancing/legal accounting entity. An example would be a company with independent accounts within a corporate group. 

Financial statements required by law can be created at company code level. Therefore, a company code is the minimum structure necessary in SAP ERP Financials. 

In an international business, operations are often scattered across numerous countries. Since most government and tax authorities require the registration of a legal entity for every company, a separate company code is usually created per country.
