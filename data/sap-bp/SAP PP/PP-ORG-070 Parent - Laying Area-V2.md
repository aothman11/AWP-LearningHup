# PP-ORG-070 Parent - Laying Area-V2

| pp-org-070: parent - laying area |
| --- |

## Definition 

Livestock management organizational unit, that we define the structure of parent - laying farms & houses.

**Farms:**

- SAP organization to model a parent - laying farm: 

- Storage location

- Purchasing group

- SAP master data to model a parent - laying farm:

- WBS element

- Work center

- Routing

- Production version

- Quota arrangement for the assigned farm capacity to each parent breed.

- Naming convention:

- Farm code as WBS & storage location: PL & two digits for farm code (Ex. PL01)

- Farm code as work center & production version: two digits for farm type PL for normal house, PC for house type cage 1, and PD for house type cage 2.

- Farm Code as purchasing Group: one digit for livestock area P for parent - laying & two digit for SAP farm code

**Houses:**

- SAP organization to model a parent - laying house: 

- Storage location

- SAP master data to model a parent - laying house:

- WBS element

- Consider the house capacity in the farm assigned quota to each parent - laying breed.

- Naming convention:

- House code as WBS: 4 digit for farm code then  “-“ then 2 digit for house code (Ex. PL01-01)

- House code as storage location: two digit SAP farm code & two digit for house code (ex. 0101)
