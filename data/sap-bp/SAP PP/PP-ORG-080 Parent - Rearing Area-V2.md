## Definition 

Livestock management organizational unit, that we define the structure of parent - rearing farms & houses.

**Farms:**

- SAP organization to model a parent - rearing farm: 

- Storage location

- Purchasing group

- SAP master data to model a parent - rearing farm:

- WBS element

- Work center

- Routing

- Production version

- Quota arrangement for the assigned farm capacity to each parent breed.

- Naming convention:

- Farm code as WBS & storage location: PR & two digits for farm code (Ex. PR01)

- Farm code as work center & production version: two digits for farm type PR for normal house.

- Farm Code as purchasing Group: one digit for livestock area R for parent - rearing & two digit for SAP farm code

**Houses:**

- SAP organization to model a parent - rearing house: 

- Storage location

- SAP master data to model a parent - rearing house:

- WBS element

- Consider the house capacity in the farm assigned quota to each parent - rearing breed.

- Naming convention:

- House code as WBS: 4 digit for farm code then  “-“ then 2 digit for house code (Ex. PR01-01)

- House code as storage location: two digit SAP farm code & two digit for house code (ex. 0101)
