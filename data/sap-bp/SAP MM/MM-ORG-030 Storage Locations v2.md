# MM-ORG-030 Storage Locations

## Definition 

An organizational unit allowing differentiation between the various stocks of a material in a plant.

A [storage location](sapevent:DOCU_LINK\DS:GLOS.3526BEADAFAB52B9E10000009B38F974) is the place where stock physically kept within a plant.

A storage location has the following attributes:

- There may be one or more storage locations within a plant.

- A storage location has a description and at least one address.

- It is possible to store material data specific to a storage location.

- Stocks managed only on a quantity basis and not on a value basis at storage location level.

- Physical inventories carried out at storage location level.
