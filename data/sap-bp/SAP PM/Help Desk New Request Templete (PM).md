# Help Desk New Request Templete (PM)

Help Desk Request for SAP Plant Maintenance Module




 • Once you open the help desk page from the browser go to
   Report an Issue




 • After that click on Others
• Then click on Default Request




• Select the Location
• Select the Category SAP Services
• Select the Subcategory SAP PLANT MAINTENANCE
  Process (PM)
• Select the Item related to your case
• Add a Subject for the request
 •   Describe your case in the Description
 •   Add your Username & Extension or Phone number
 •   Select the Service Category SAP Service
 •   Add attachment for the case if available
 •   After you finish click on Add Request
